# Практическое задание 06: меню, контекстное меню и панель инструментов (WinForms)

Готовый проект Windows Forms (.NET Framework 4.7.2) по заданию 06.
Персонаж двигается по окну. Им управляют главное меню, горячие клавиши,
контекстное меню и панель инструментов.

## Как открыть

1. Откройте `Practice06.sln` в Visual Studio.
2. Нажмите **F5**.

Можно и по-другому: перенесите в свой проект `Практика_4` файлы `Pic.cs`, `Form1.cs`,
`Form1.Designer.cs` и `Form1.resx` с заменой. Старый `Pic_3.cs` удалите из проекта,
иначе класс `Pic` будет объявлен дважды. Пространство имён везде одно — `Практика_4`.

## Обязательно: пересоберите imageList1 (1 минута)

В вашем `imageList1` картинки сохранены в размере **16×16** с 8-битным цветом
(это настройки ImageList по умолчанию). Поэтому персонажи из меню «Вид» выглядят
как пиксельный квадрат. Исходных картинок в проекте нет, поэтому заново их добавить
можете только вы:

1. Откройте `Form1.cs` в конструкторе и выделите `imageList1` (внизу, под формой).
2. В окне «Свойства» удалите все три картинки из `Images`.
3. Поставьте `ColorDepth` = `Depth32Bit`, `ImageSize` = `128; 128`.
4. Через `Images` → «Добавить» добавьте те же файлы в том же порядке:
   **Лосяш, Пин, Крош**.

Код менять не нужно: картинки в меню «Вид» и в контекстном меню подтянутся из imageList сами.

## Что сделано по задачам

**Задача 1 — главное меню** из пяти групп: Направление, Вид, Размер, Скорость, Выход.
У каждого пункта выпадающего меню есть рисунок и горячая клавиша.
Галочка показывает текущий выбор.

| Меню | Пункты и клавиши | Что делает обработчик |
|---|---|---|
| Направление | Влево `Ctrl+←`, Вправо `Ctrl+→`, Вверх `Ctrl+↑`, Вниз `Ctrl+↓` | `myperson.Dir = 1..4` |
| Вид | Лосяш `Ctrl+1`, Пин `Ctrl+2`, Крош `Ctrl+3` | `pictureBox1.Image = imageList1.Images[i]` |
| Размер | Большой `Ctrl+B`, Маленький `Ctrl+M` | `myperson.Size = 150 / 80` |
| Скорость | Медленно `Ctrl+S`, Быстро `Ctrl+F` | `timer1.Interval = 100 / 30` |
| Выход | `Alt+Х` | `Close()` |

Таймер (`timer1`) включён и на каждом тике вызывает `myperson.Draw(pictureBox1)`.

**Задача 2 — картинка не уходит за край.** В `Pic.Draw` размер контейнера берётся
у родителя PictureBox: `Pb.Parent.ClientSize`. PictureBox лежит в `panel1` (Dock = Fill),
поэтому меню и панель инструментов не перекрывают картинку. Окно можно растягивать
и сжимать, картинка всё равно останется внутри. У края картинка останавливается
(«иначе стоять»), как в задании. Если сделать её «Большой» у самого края,
она тоже не вылезет.

> Почему не `Form1 frm = new Form1(); int W = frm.Width;` из подсказки.
> Если написать это в `Draw`, на каждом тике таймера создаётся новая скрытая форма.
> Программа тормозит, картинка дёргается, растёт расход памяти.
> Если написать в поле класса `Pic`, получится бесконечная рекурсия: форма создаёт Pic,
> Pic создаёт форму… Кроме того, `new Form1()` знает только исходную ширину окна,
> а не текущую.

**Задача 3 — контекстное меню картинки** (`contextMenuStrip1`, правая кнопка мыши
по персонажу). Оно повторяет пункты меню «Вид» и вызывает их через `PerformClick()`.
Меню связано с картинкой свойством `pictureBox1.ContextMenuStrip`.

**Задача 4 — панель инструментов**: кнопки ← → ↑ ↓ и выпадающий список «Медленно / Быстро».
Обработчики панели вызывают пункты главного меню (`PerformClick()`).
Список и меню «Скорость» показывают одно и то же значение.

## Что было не так в исходной версии

- `Pic` лежал в другом пространстве имён (`Для_практики_4_Меню_Объект`), не там, где форма (`Практика_4`).
- В разметке у таймера не было `Enabled = true` и `Interval`. Если таймер не запускался в `Form1.cs`,
  картинка стояла на месте.
- В `Pic` не было `Up()` / `Down()` и не было ограничения по краям.
- Пункты «Вниз», «Вправо», «Влево» не были подключены к обработчикам. Не хватало пунктов
  «Скорость → Медленно/Быстро» и «Выход», контекстного меню и обработчика выпадающего списка.
- Подписи горячих клавиш в меню («Вверх CTRL + Down») были просто текстом,
  сами клавиши не работали. Теперь задано свойство `ShortcutKeys`.
- `Pb.Left`, `Pb.Top`, `Pb.Width`, `Pb.Height` задавались четырьмя командами,
  и картинка могла мерцать. Теперь используется одна команда `Pb.SetBounds(...)`.
