# Практика 5 — «Маленький текстовый редактор» (SDI-интерфейс)

Решение практического задания 08: SDI-интерфейс настольного приложения, меню,
панель инструментов, строка состояния. Windows Forms, .NET Framework 4.7.2.

## Как открыть

1. Откройте `Практика_5.sln` в Visual Studio.
2. Нажмите **F5**.

## Что сделано по шагам задания

**Шаг 1 — главное меню (MenuStrip).** Пункты и имена такие же, как при команде
«Вставить стандартные элементы» (`newToolStripMenuItem`, `openToolStripMenuItem` и т. д.),
поэтому код совпадает с кодом из задания. Лишние стандартные пункты (Печать, Сервис)
убраны.

| Меню | Пункты (горячие клавиши) |
|---|---|
| Файл | Создать `Ctrl+N`, Открыть `Ctrl+O`, Сохранить `Ctrl+S`, Сохранить как `Ctrl+Shift+S`, Выход `Alt+F4` |
| Правка | Отменить `Ctrl+Z`, Вернуть `Ctrl+Y`, Вырезать `Ctrl+X`, Копировать `Ctrl+C`, Вставить `Ctrl+V`, Выделить все `Ctrl+A` |
| Справка | О программе `F1` |

**Шаг 2 — панель инструментов (ToolStrip, Dock = Top).** Кнопки Создать, Открыть,
Сохранить, | Вырезать, Копировать, Вставить, | Справка. У каждой кнопки заданы
`Text` и всплывающая подсказка `ToolTipText`. Кнопки «Сохранить как», как сказано
в задании, на панели нет.

**Шаг 3 — окно редактирования (RichTextBox).** Свойства как в задании:
`BorderStyle = Fixed3D`, `ScrollBars = Both`, `Dock = Fill`, `Multiline = True`,
`WordWrap = True`, `AutoWordSelection = True`, `ShortcutsEnabled = True`,
курсор `IBeam`. Дополнительно `AcceptsTab = True`, чтобы Tab вставлял табуляцию.

**Шаг 4 — обработчики меню «Файл»** (`using System.IO;`, глобальная переменная
`String File_name = "Noname.rtf";`):
- **Создать** очищает окно и задаёт имя `Noname.rtf`.
- **Открыть** использует `openFileDialog1` с фильтром
  `Rtf файлы (*.rtf)|*.rtf|Текстовые файлы (*.txt)|*.txt|Все файлы (*.*)|*.*`.
- **Сохранить как** использует `saveFileDialog1`.
- **Сохранить** работает так: если имя всё ещё `Noname.rtf`, вызывается
  «Сохранить как», иначе файл записывается молча.
- Диалоги открываются в папке «Документы» (`InitialDirectory`, см. «Замечание» в задании).

**Шаг 5 — один обработчик на всю панель:** `toolStrip1_ItemClicked`. Номер кнопки
`toolStrip1.Items.IndexOf(e.ClickedItem)` выбирает, какой обработчик меню вызвать.

**«Выход» и сохранение текста.** Если в тексте есть несохранённые изменения,
редактор спрашивает «Сохранить изменения?» с вариантами Да / Нет / Отмена.
Вопрос задаётся при «Создать», «Открыть», «Выход», а также при закрытии
крестиком или Alt+F4. «Отмена» оставляет вас в редакторе. Изменения отслеживаются
свойством `richTextBox1.Modified`.

**Дополнительно (из лекции):**
- **Строка состояния (StatusStrip).** Показывает имя файла, признак «Изменён»,
  строку и столбец курсора и число символов.
- **Заголовок окна** выглядит как в обычном редакторе: `Noname.rtf* — Маленький текстовый редактор`.
- **Контекстное меню** окна текста: Отменить, Вырезать, Копировать, Вставить,
  Выделить все. Оно повторяет пункты главного меню.
- **«Вставить»** работает через буфер обмена, как в лекции. Сначала
  `Clipboard.ContainsData` проверяет формат (RTF или простой текст), потом
  вызывается `richTextBox1.Paste(формат)`.

## Чем код отличается от примеров в задании и почему

- **«Сохранить как».** В примере написано `File_name = saveFileDialog1.FileName + ".rtf";`.
  Но диалог сам добавляет расширение (`DefaultExt = "rtf"`), и получилось бы `файл.rtf.rtf`.
  Поэтому имя берётся из диалога без добавок.
- **Файлы `.txt`.** `LoadFile(..., RichText)` выдаёт ошибку на обычном текстовом файле,
  а `LoadFile(..., PlainText)` читает в кодировке ANSI, и русский текст из UTF-8
  превращается в «кракозябры». Поэтому `.rtf` открывается через `LoadFile`/`SaveFile`,
  как в задании, а `.txt` — через `File.ReadAllText`/`File.WriteAllText` из `System.IO`.
- **Ошибки при открытии и сохранении** (файл занят, повреждён) не роняют программу,
  а показываются в `MessageBox`.
- **`BorderStyle = Fixed3D` для панели инструментов.** У компонента ToolStrip
  такого свойства нет, оно есть только у RichTextBox.

## Иконки

Иконки на кнопках и в меню взяты из набора Tango (общественное достояние),
размер 16×16, как рекомендует лекция.
