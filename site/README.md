# Сайт ARZHEVITIN

Одна статическая страница: `index.html` + фото в `img/`. Сборка не нужна, достаточно открыть файл
или выложить папку на любой хостинг (GitHub Pages, Netlify, свой сервер).

Фото — кадры из роликов бренда в `output/` (без надписей; где снизу были субтитры, кадр обрезан).
С arzhevitin.ru фото взять не удалось: сайт недоступен из окружения, где делалась страница.

Заменить перед запуском:
- ссылки Telegram и Instagram в блоке «Написать» (помечены комментарием `ЗАМЕНИТЬ`);
- «Цена по запросу» — на цены, если нужны;
- фото — на студийные с arzhevitin.ru, если они лучше (имена файлов в `img/` можно оставить прежними).
