# Монтаж роликов бренда

- `style/montage-style.md` — стиль монтажа (v1.0).
- `engine/montage.py` — движок: цветокор, зумы и тряска, растворения, хук, плашка раздела,
  кольцо удара, выноска с трекингом, субтитры по словам, обработка голоса, саунд-дизайн, −14 LUFS.
- `engine/fonts/` — Inter и Lora (OFL, из пакетов @fontsource).
- `projects/` — таймлайн каждого ролика. Запуск:
  `pip install numpy pillow opencv-python-headless fonttools && python3 projects/2026-10-05_kirka.py test_2.mp4 output`
- `engine/transcribe.py` — распознавание речи (faster-whisper large-v3-turbo) с таймингом слов и разбивкой
  на субтитры по 1–2 слова: `python3 engine/transcribe.py видео.mp4 projects/имя.words.json`.
  Нужны `pip install faster-whisper` и доступ к `huggingface.co`, `*.hf.co` (модель ~1,6 ГБ качается при первом запуске).
  В JSON можно поправить слова и отметить акценты (`"accent": true`).
- `output/` — готовые ролики.

## 2026-10-05 «кирка» v5 (16,0 сек) — новый стиль (`style/montage-style-v2.md`)

шторки, бордовая карточка «некачественная», два коллажа из вырезок (вы в бордовом круге; кожа в коричневом),
субтитры из распознавания (`projects/2026-10-05_kirka.words.json`). Вырезано: лишний звук в начале (0–1,6 с),
«да», «то есть», «то есть уже странно». «Большая вмятина» — голос из 20,3 с, картинка вмятины из 22,15 с.

Сборка: `python3 projects/2026-10-05_kirka_v5.py test_2.mp4 output` (нужны onnxruntime, huggingface_hub, доступ к huggingface.co / *.hf.co для модели вырезки).
