# Монтаж роликов бренда

- `style/montage-style.md` — стиль монтажа (v1.0).
- `engine/montage.py` — движок: цветокор, зумы и тряска, растворения, хук, плашка раздела,
  кольцо удара, выноска с трекингом, субтитры по словам, обработка голоса, саунд-дизайн, −14 LUFS.
- `engine/fonts/` — Inter и Lora (OFL, из пакетов @fontsource).
- `projects/` — таймлайн каждого ролика. Запуск:
  `pip install numpy pillow opencv-python-headless fonttools && python3 projects/2026-10-05_kirka.py test_2.mp4 output`
- `output/` — готовые ролики.
