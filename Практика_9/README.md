# Практика 9: прикладная задача на списке

Приложение Windows Forms (.NET Framework 4.7.2) по пунктам 1–3 методички «Практическое задание 09-10».
Таблица сотрудников: имя, дата рождения, должность, отдел, оклад.

Работа с файлами, импорт в Word, Excel и NotePad, а также панель инструментов (пункты 4–5)
относятся к практике 10. Они сделаны отдельно, в папке `Практика_9-10`.

## Как запустить

Открыть `Практика_9.sln` в Visual Studio (2019 или 2022) и нажать F5. Внешние пакеты не нужны.
При запуске в таблице уже есть 5 записей: по методичке список заполняется в коде формы.

## Что где лежит

| Файл | Пункт методички |
|---|---|
| `Record.cs` | 2. Класс записи: свойства, конструкторы (по умолчанию, с параметрами, копирования), `ToString`, проверка полей |
| `Form1.cs` | 2–3. `List<Record> Table` с начальными данными, `static public Record Rec`, `Redraw()`, текущая запись в `textBox1` по `CellClick` |
| `DialogAdd.cs` | 3.1. Окно «Добавить»: текстовые поля, `DateTimePicker`, `ListBox` с отделами, проверка ввода, `MessageBox` при ошибке |
| `DialogEdit.cs` | 3.2. Окно «Изменить»: то же, поля заполнены текущей записью |
| `Form1.cs`, «Удалить» | 3.3. Удаление с подтверждением через `MessageBox` |

Меню: Файл (Выход), Правка, Операции с данными, Справка, Выход.
Сверх методички: «Отмена действия» работает для добавления, изменения, удаления и сортировки.
В «Операциях с данными» есть сортировка и итоги по отделам.

## Горячие клавиши

| Пункт | Клавиши |
|---|---|
| Отмена действия | Ctrl+Z |
| Добавить / Изменить / Удалить | Ctrl+A / Ctrl+E / Ctrl+D |
| Выделить все | Ctrl+Shift+A |
| Итоги по отделам | Ctrl+T |
| О программе | F1 |

В таблице: двойной щелчок или Enter открывает изменение записи, Delete удаляет её.
