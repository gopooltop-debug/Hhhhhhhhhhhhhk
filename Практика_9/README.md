# Практика 9-10: прикладная задача на списке

Приложение Windows Forms (.NET Framework 4.7.2) по методичке «Практическое задание 09-10».
Таблица сотрудников: имя, дата рождения, должность, отдел, оклад.

## Как запустить

1. Открыть `Практика_9.sln` в Visual Studio (2019 или 2022).
2. Нажать F5. При первой сборке Visual Studio сама скачает NuGet-пакеты
   `Microsoft.Office.Interop.Excel` и `Microsoft.Office.Interop.Word` в папку `packages`.
3. В программе: Файл → Открыть → `Сотрудники.txt` (лежит рядом с проектом и копируется в `bin\Debug`).

Для импорта в Word и Excel нужен установленный Microsoft Office. Без него остальное работает,
а при импорте появится сообщение об ошибке.

## Что где лежит

| Файл | Пункт методички |
|---|---|
| `Record.cs` | 2. Класс записи: свойства, конструкторы (по умолчанию, с параметрами, копирования), `ToString`, `ToFileString` (поля через `#`), `Parse`, проверка полей |
| `Form1.cs` | 3. Главная форма: `List<Record> Table`, `static public Record Rec`, `Redraw()`, текущая запись в `textBox1`, обработчики меню и панели инструментов |
| `DialogAdd.cs` | 3.1. Окно «Добавить»: текстовые поля, `DateTimePicker`, `ListBox` с отделами, проверка ввода |
| `DialogEdit.cs` | 3.2. Окно «Изменить»: то же, поля заполнены текущей записью |
| `Form1.cs`, «Удалить» | 3.3. Удаление с подтверждением через `MessageBox` |
| `Form1.cs`, «Файл» | 4.1–4.4. Открыть (`StreamReader`), Сохранить (`StreamWriter`), Сохранить как (`saveFileDialog`), Создать (с вопросом о сохранении) |
| `Form1.cs`, «Импорт» | 4.5. Excel (таблица на лист, итог формулой), Word (справка о зарплате: имя, отдел, оклад), NotePad |
| `Form1.Designer.cs` | 5. Панель инструментов с кнопками, дублирующими меню |

Сверх методички: «Отмена действия» (Ctrl+Z) работает для добавления, изменения, удаления и сортировки;
в «Операциях с данными» есть поиск по имени, сортировка и итоги по отделам; строка состояния
показывает число записей и имя файла; при закрытии программы с несохранёнными изменениями
появляется вопрос о сохранении.

## Горячие клавиши

| Меню | Пункт | Клавиши |
|---|---|---|
| Файл | Создать / Открыть / Сохранить / Сохранить как | Ctrl+N / Ctrl+O / Ctrl+S / Ctrl+Shift+S |
| Файл → Импорт | Word / Excel / NotePad | Ctrl+W / Ctrl+Shift+E / Ctrl+Shift+N |
| Правка | Отмена / Добавить / Изменить / Удалить / Выделить все | Ctrl+Z / Ctrl+A / Ctrl+E / Ctrl+D / Ctrl+Shift+A |
| Операции с данными | Найти / Итоги по отделам | Ctrl+F / Ctrl+T |
| Справка | О программе | F1 |

В методичке для Excel указано Ctrl+E, а для NotePad — Ctrl+N, но эти сочетания уже заняты пунктами
«Изменить» и «Создать». Поэтому у импорта добавлен Shift.

В таблице: двойной щелчок или Enter открывает изменение записи, Delete удаляет её.

## Формат файла

Одна строка — одна запись, поля разделены `#`, дата в виде `дд.мм.гггг`, оклад через точку:

```
Иванов Иван Иванович#12.03.1985#Главный бухгалтер#Бухгалтерия#85000
```

Файлы сохраняются в UTF-8. Открываются и UTF-8, и ANSI (Windows-1251), то есть файл из Блокнота
читается в любой из этих кодировок. Строки с ошибками пропускаются, а программа сообщает их номера.
